Mode d'emploi

  1. Créez un site dans le dashboard et copiez sa clé publique (wz_…)
  2. Collez-la ci-dessous puis validez — la page se recharge avec le widget actif
  3. Naviguez entre les liens, puis fermez l'onglet pour déclencher l'envoi de la durée
  4. Vérifiez la table sessions dans Supabase

/pricing /docs /blog

Chaque clic compte une page vue supplémentaire dans la session en cours. La durée n'est envoyée qu'à la fermeture de l'onglet ou au changement d'application.

Mur d'avis

La balise ci-dessous est remplie par le script avec les avis publiés uniquement. Si rien n'apparaît, c'est qu'aucun avis n'est encore publié — allez en publier un depuis le dashboard.
